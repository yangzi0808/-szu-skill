# 前四项写什么、写多少、怎么写

## 精简的标尺

报告是 PPT 的浓缩，不是 PPT 的誊写。用一篇"用户认可"的同类报告做标尺最准：
本 skill 的标尺来自《干涉法测热膨胀系数》（前四项约 3–4 页、6 张图、3 个公式，
而它的 PPT 有 13 页）。

据此，前四项的目标体量：

| 指标 | 目标 |
| --- | --- |
| 篇幅（含封面） | 4–8 页；前四项占 3–6 页 |
| 插图 | 5–8 张 |
| 编号公式 | 3–6 个 |
| 原理段数 | 4–9 段，每段 1–3 行 |
| 步骤 | 每个大步骤 2–4 条，每条 1–2 行 |

超过这个量级时，先砍这几类内容：软件菜单截图、重复的过程照、说明性长文的逐句照抄、
次要公式（改成一句话带过）。

## 每一节写什么

**一、实验目的** —— 直接抄 PPT 的目的条目，一条一行，不加解释。

**实验原理** —— 按逻辑分 3–5 个小标题（如 光谱的产生 / 光栅的色散 / 分辨本领与角色散 /
基本结构和光路）。每段先用一句 PPT 原话点题，再给必要的公式，最后给一张原理图。
只保留核心公式；次要结论（例如某参数取某值时算得某个数）写进正文一句带过，不单独占一行公式。

**实验仪器** —— 学参考报告那样列要点：一段总述 + 4–6 条一行的条目
（光学系统 / 接收器件 / 光源 / 电子系统 / 软件系统），末尾配一张装置实物或内部结构图。
不要把说明书原文整页抄进来；说明书扫描件也不要当插图用。

**四、实验内容与步骤** —— 按 PPT 的顺序保留全部步骤，但压成条目式：

```
1、开机前准备工作
① …
② …
注意：…（安全提示必须保留）
2、开机与系统复位
…
```
正式编号用 `①②③`（与参考报告一致）。关键参数（狭缝宽度、负高压数值、扫描间隔、
波长范围、等待时间）一个都不能少。校准用的标准谱线值适合做成一张小表。

## 忠实度的取舍

| 情况 | 处理 |
| --- | --- |
| PPT 原话可直接用 | 照抄，可以断句、合并，不改术语与数值 |
| PPT 太啰嗦 | 压缩成短句；**参数、单位、条件、注意事项不得丢** |
| PPT 内部矛盾（图注与正文符号不一致） | 正文用更合理的写法，图注里附上原文，并在交付说明里列为待确认 |
| 明显同音错别字（纳灯→钠灯、发射镜→反射镜） | 直接更正，交付说明里提一句 |
| 图片文字被裁切 | 按可见文字补全并标注"需核对" |
| PPT 没写的内容 | 不要发明。写【PPT未说明，需补充】或直接问用户 |

## 公式

1. 先判断哪些是"公式"、哪些只是"行内符号"。
2. **独立公式**用 Word 原生公式，居中，右侧编号（1）（2）…，与参考报告一致。
3. **行内符号**用普通文字：`λ`、`Δλ`、`Δθ`、`M₁`、`S₂`、`d = a + b`、`d sinθ = kλ`。
   不要把 `$...$` 或 `\lambda` 留在文档里——那是上一版被用户退回的原因。
4. 可以合并重复公式（例：`hγ = ΔE` 与 `ΔE = hν = …` 只留后者）；合并时在交付说明里讲明。
5. 公式里的符号、上下标、单位一律照 PPT，不换算、不改写。

写法与代码示例见 [equations.md](equations.md)。

## 图注与表注

```
图 2-1  氢原子能级跃迁图（来源：PPT 第 2 页）
表 4-1  校准用标准谱线波长（来源：PPT 第 13 页）
```

* 章号用报告里的节号（2 = 实验原理，3 = 实验仪器，4 = 实验内容与步骤）。
* PPT 原有图注优先沿用（如"图 16-2 光栅的衍射"），再补来源页。
* 没有图注时按上下文写一句准确、不夸大的题名；写不出准确题名就说明它属于哪一步。
* 图注字号比正文小一号（本模板正文五号，图注小五=9pt）。
